[붙임2-1] 서식 2_프로젝트 요약서(AI핵심 및 AI융합 과정)1장 이내로 요약

제안과제명성분돋보기: 화장품 광고 문구에 성분 이름을 쓸까, 소비자 리뷰의 말을 쓸까
팀명(별명)성분돋보기 (차원식, 권지원)

1. 프로젝트 개요

○화장품 광고 문구에 성분 이름과 리뷰 언어(리뷰에 나오는 사용감 표현) 중 무엇을 써야 반응이 더 오는지 소액 Meta 광고 A/B 테스트로 검증 (7일씩 두 번: 1차 이미지, 2차 문구. 광고비 14만 원)

○클릭에서는 두 문구의 차이가 보이지 않았고 관심은 클릭 뒤 랜딩에서 대부분 끊김. 다음 투자는 문구가 아니라 랜딩

-리포트 seongbun-dotbogi.vercel.app/report, 저장소 github.com/Chawonsik/seongbun-dotbogi

2. 문제 정의

○가정한 사용자: PDRN(연어 DNA 유래 성분) 크림 출시를 앞두고 광고 문구를 정해야 하는 브랜드 마케터

○성분 이름을 앞세운 제품이 많고(화장품 리뷰 앱 화해에서 "PDRN" 검색 결과 1,824개) 브랜드가 달라도 광고 문구는 서로 비슷함

○화해 비즈니스 글(2026년 4월 13일)은 광고 문구도 리뷰 언어로 쓰라고 권하지만 실험 근거는 없음

○가설: 리뷰 언어 문구의 링크 클릭률이 성분 이름 문구보다 높을 것

3. 해결 방안과 검증 결과

○한 번에 하나만 바꾼 2단계 실험. 1차는 이미지만 다르게 해 2차에 쓸 이미지를 고르고 2차는 같은 이미지 위의 문구("PDRN 연어크림" 대 "바르면 쫀쫀해지고 광이 나는 크림")만 다르게 함

○1차는 Meta가 노출의 93%를 한쪽에 몰아줌. 2차는 광고마다 광고 세트(예산 단위)를 두고 예산을 고정해 노출을 51.2% 대 48.8%로 맞춤

○광고를 누르면 판매하지 않는다고 밝힌 콘셉트 랜딩으로 이어지고 관심 버튼 클릭을 기록

○결과 1: 링크 클릭률 성분 이름 2.97% 대 리뷰 언어 2.77%, z검정 p = 0.48. 차이가 유의하지 않아 가설은 지지되지 않음

○결과 2: 노출 13,414회 → 링크 클릭 385회 → 랜딩 도착 365대 → 관심 표시 3대. 관심 표시 1대에 광고비 약 23,300원

4. 실현 가능성

○실제 광고 집행으로 끝까지 검증했고 같은 방식으로 다시 할 수 있음. 광고 이름을 그대로 UTM 값으로 써서 Meta 광고 수치와 랜딩 행동을 광고 단위로 연결. 이벤트 8개는 정의 파일 하나로 관리하고 자동 검사

○Meta 광고 관리자와 Amplitude를 MCP로 Claude에 연결해 조회와 분석을 한곳에서 처리. 리포트와 차트는 스크립트로 다시 만들어지고 규칙과 플레이북은 공개

5. 기대효과 및 활용

○리뷰 언어로 바꿀 근거가 없으니 성분 이름 문구로 가도 됨. 0.2%p 차이를 가리려면 광고당 노출 약 10만 회, 약 15주가 필요하고 그 사이 랜딩 도착 기기의 99%가 떠남. 문구보다 랜딩에 먼저 투자

○다음 단계: 광고는 그대로 두고 랜딩에 "성분 자세히"와 "후기 보기" 버튼을 두어 두 언어를 클릭 뒤에서 비교. 관심 표시 1대당 광고비를 기준값으로 효과를 잼

○한계: 광고당 노출 약 6,700회라 작은 차이는 못 가림(차이의 95% 신뢰구간 −0.36 ~ 0.77%p). 클릭 단계까지만 쟀고 가상 제품이며 노출의 약 3분의 2가 20~24세 릴스 이용자임

AI 및 외부 소재의 출처: 화해 비즈니스 인사이트 글(2026년 4월 13일)을 인용하고 검색 결과 수는 화해 앱에서 직접 확인함. 광고 이미지는 GPT로, 랜딩 사진 네 장은 Canva 이미지 생성으로 만듦. 코드와 문서 초안은 Claude로 쓰고 사람이 검토함. 광고 게시와 예산 설정은 모두 사람이 함
