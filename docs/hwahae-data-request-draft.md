# 화해 데이터 협조 요청 메일 초안

보내는 곳 후보: 화해 비즈니스(business.hwahae.co.kr) 문의, 또는 광고/제휴문의(www.hwahae.co.kr 하단 링크). 결과를 기다리지 않고 병행한다.

---

제목: 성분 표기 순서 연구를 위한 전성분 데이터 협조 요청

안녕하세요. 개인 학습 프로젝트 "성분돋보기"를 진행하는 [이름]입니다.

저희는 "제품명에 넣은 유행 성분이 전성분 표기 순서에서 실제로 어디에 있는가"를 분석하고, 그 결과를 광고 문구 실험(성분 이름, 함량 위치, 리뷰 언어 프레임 비교)에 쓰려고 합니다. 화해 광고 사업부가 브랜드에 권하는 "원료사 카피 대신 리뷰 언어" 주장을 소액 광고 실험으로 검증해 보는 것이 목적입니다.

이를 위해 아래 범위의 데이터를 제공받을 수 있는지 문의드립니다.

- 대상: 제품명에 유행 성분 이름(PDRN, 레티놀 등 10개 내외)을 단 제품, 성분당 20~50개, 총 500개 이내
- 항목: 제품 번호, 제품명, 브랜드, 전성분 표기 순서(성분 번호와 이름), 등록 시점
- 용도: 표기 순서 위치, 1% 이하 추정 구간, 성분 계열 동시 포함 여부 같은 파생 지표 계산. 전성분 원문은 재배포하지 않고 파생 지표만 공개
- 출처 표기: "데이터: 화해(hwahae.co.kr) 전성분, 수집일 기준" 으로 결과물 하단에 명시

현재는 화해 웹 페이지를 사람이 직접 열어 확인하는 방식으로 소량만 보고 있으며, 자동 수집 도구는 사용하지 않고 있습니다. 제공이 어렵다면 어떤 범위와 조건이면 가능한지, 또는 화해 비즈니스의 인사이트 서비스로 대체할 수 있는지 안내 부탁드립니다.
