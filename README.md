## 1. 문제 정의

**대상과 문제 한 문장**
PDRN 크림 출시를 앞둔 브랜드 마케터(가정)는 출시 광고에서 성분 이름("PDRN 연어크림")과 후기의 말("바르면 쫀쫀해지고 광이 나는 크림") 중 무엇을 앞세울지 근거 없이 정해야 합니다.

**왜 이 문제인가**
성분 이름을 앞세운 화장품이 크게 늘어나는 것을 흥미롭게 보고 있었습니다. 실제로 이름에 PDRN을 단 제품 6개의 성분표를 확인해 보니 3개는 PDRN이 성분표 후반부에 적혀 있었습니다(2026-09-18). 그러던 중 화해 비즈니스의 글을 읽었습니다([2026-04-13 글](https://business.hwahae.co.kr/insight/beauty-ingredient-marketing-guide/)). 브랜드에게 성분 이름 대신 후기의 말을 쓰라고 권하는 글인데 그 말이 실제로 반응을 더 끈다는 근거는 없었습니다. 그래서 두 문구를 광고로 직접 비교해 보기로 했습니다.

- 화해 웹에서 "PDRN"을 검색하면 제품이 1,816개 나옵니다(2026-10-01 확인, 제품 수 기준).
- 식약처의 PDRN 화장품 광고 적발은 2023년 7건에서 2026년 상반기 41건으로 늘었습니다([약사공론](https://www.kpanews.co.kr/news/articleView.html?idxno=538280)).

**왜 PDRN 크림인가**
처음에는 "성분 이름을 앞세운 마케팅이 통하는가"를 여러 성분에 걸쳐 확인하고 싶었습니다. 하지만 광고 A/B 테스트는 제품 하나에 문구만 바꿔 비교해야 해서 성분을 하나로 정해야 했습니다. 화해 비즈니스 글이 예로 든 성분 가운데 PDRN을 골랐습니다. 같은 글에 나온 나이아신아마이드는 이름에 내세우지 않은 제품에도 널리 들어가는 성분이라 뺐습니다. 화해 웹 검색 결과가 "나이아신아마이드" 79,549개, "PDRN" 1,824개입니다(2026-10-12 확인). 제형과 성분 이름 문구는 강사 피드백의 예시("PDRN 연어크림")를 따랐습니다.

**왜 가상 제품인가**
이 프로젝트의 1순위는 문구 검증입니다. 실제 제품을 만들 수 있는 여건이 아니었고 문구에 대한 반응을 보는 데는 제품이 꼭 필요하지 않아서 가상 제품의 콘셉트 페이지로 진행했습니다.

**비즈니스 임팩트**
우리가 잰 수치로만 적습니다. 가상 제품이라 매출은 측정하지 않았습니다.

| 항목 | 수치 |
|---|---|
| 실험에 쓴 광고비 | 1차 69,937원(7일), 2차는 하루 10,000원으로 진행 중 |
| 링크 클릭 한 번의 비용 | 광고에 따라 132원에서 313원(1차), 201원과 216원(2차 중간) |
| 랜딩에 도착한 뒤 관심을 표시한 기기 | 1차 471대 중 3대 |

1차에서는 같은 광고비로 얻는 클릭 수가 광고에 따라 두 배 넘게 달랐고 클릭이 관심으로 이어진 비율은 1%에 못 미쳤습니다. 문구를 고르는 일과 도착한 사람을 붙잡는 일 모두 광고비의 효율을 좌우합니다.

**성공 기준**
- 시작 전(2026-10-01)에 정한 것: 주 지표는 광고 관리자의 CTR(링크 클릭률), 보조 지표는 랜딩의 관심 버튼 클릭률. 두 소재의 CTR 차이를 판단하는 숫자도 정해 두었습니다.
- 바꾼 것(2026-10-07): 1차는 Meta가 한쪽 광고에 노출을 몰아줘서 미리 정한 숫자를 쓸 수 없었습니다. 강사 피드백을 받고 판단 숫자를 뺐습니다. 2차는 두 문구의 CTR을 노출 수와 함께 그대로 비교하고 차이가 애매하면 기간을 늘리는 식으로 상황에 맞춰 정합니다.

**Focus 지표와 선행지표**
- Focus 지표: CTR(링크 클릭률) = 링크 클릭 ÷ 노출. 좋아요나 프로필 누르기까지 세는 CTR(전체)는 쓰지 않습니다. 실제로 보고 싶은 것은 구매 전환이지만 제품이 출시 전이라 구매를 잴 수 없습니다. 이 단계에서 확인하려는 것은 어떤 그림과 문구가 더 선택되는가여서 광고를 보고 누른 비율을 주 지표로 삼았습니다.
- 선행지표: 광고별 노출 비중과 노출 1,000회당 비용. 두 광고가 비슷하게 노출돼야 CTR을 비교할 수 있습니다.
- 보조 지표: 랜딩에 도착한 기기 중 관심 버튼을 누른 비율.

## 3. 분석과 검증

2차 수치는 2026-10-11 21:57에 조회한 중간값입니다. 2차는 10-16 18:00에 끝납니다.

### 3.1 1차: Meta가 노출을 한쪽에 몰아줬다

**사실**

| | 원료 그림 | 사용감 그림 |
|---|---|---|
| 노출 | 1,000 (7%) | 12,346 (93%) |
| 링크 클릭 | 28 | 464 |
| CTR(링크 클릭률) | 2.80% (28/1,000) | 3.76% (464/12,346) |
| 지출 | 8,761원 | 61,176원 |

| 일자별 노출 | 10/2 | 10/3 | 10/4 | 10/5 | 10/6 | 10/7 | 10/8 | 10/9 |
|---|---|---|---|---|---|---|---|---|
| 원료 | 57 | 658 | 260 | 24 | 0 | 1 | 0 | 0 |
| 사용감 | 19 | 1,003 | 1,765 | 2,506 | 2,178 | 1,928 | 2,111 | 836 |

- 두 광고가 함께 나간 10/3과 10/4만 보면 CTR이 2.72%(25/918) 대 2.89%(80/2,768)입니다.
- 타겟 설정은 같았지만 실제로 본 사람의 구성이 달랐습니다. 인스타그램 릴스 78% 대 99%, 아이폰 66% 대 99%, 20~24세 23% 대 62%.

**해석**
1차는 광고 세트 하나에 광고 두 개를 넣었고 Meta가 한쪽에 노출을 몰아줬습니다. 배분을 Meta에 맡긴 구조라 사실상 Meta가 그림을 고른 셈이 됐습니다. 전체 CTR은 사용감이 높게 나왔지만 날짜와 본 사람의 구성이 달라서 그림의 차이라고 확정하지 못했습니다. 2차에 쓸 그림은 사용감 그림으로 정했습니다. 배분을 Meta에 맡긴 이상 어떤 기준으로도 그쪽이 선택된다는 강사 피드백에 따른 것입니다. 2차에서는 광고 세트를 둘로 나누고 세트마다 예산을 고정해 두 광고가 같은 규모로 노출되게 했습니다.

### 3.2 2차(중간): 성분 이름 문구 대 후기의 말 문구

**사실**

| | A "PDRN 연어크림" | B "바르면 쫀쫀해지고 광이 나는 크림" |
|---|---|---|
| 노출 | 2,136 (50.5%) | 2,097 (49.5%) |
| 링크 클릭 | 60 | 57 |
| CTR(링크 클릭률) | 2.81% (60/2,136) | 2.72% (57/2,097) |
| 지출 | 12,036원 | 12,310원 |

| 일자별 CTR | A | B |
|---|---|---|
| 10/9 (18시 이후) | 2.76% (9/326) | 1.83% (5/273) |
| 10/10 | 1.97% (16/811) | 3.01% (21/698) |
| 10/11 (21:57까지) | 3.50% (35/999) | 2.75% (31/1,126) |

- 본 사람의 구성: 인스타그램 릴스 98% 대 97%, 20~24세 61% 대 57%, 35세 이상 14% 대 23%.

**해석**
광고 세트를 둘로 나누고 세트마다 예산을 고정하자 노출이 거의 같게 나갔고 본 사람의 구성도 1차보다 비슷해졌습니다. 지금까지 두 문구의 CTR은 거의 같고 날마다 앞서는 쪽이 바뀝니다. 화해 글의 권고(후기의 말이 낫다)를 뒷받침하는 차이도 반대 방향의 차이도 아직 보이지 않습니다.

### 3.3 랜딩: 버튼은 보이지만 눌리지 않는다

**사실**

| | 1차 | 2차(중간) |
|---|---|---|
| 광고로 도착한 기기 | 471 | 114 |
| 관심 버튼을 누른 기기 | 3 | 1 |
| 60초 머문 기기 | 0 | 1 |

| 1차 구역 노출 (10/6 17:00 ~ 10/9 17:00, 사용감 유입) | 기기 | 도착 대비 |
|---|---|---|
| 랜딩 도착 | 210 | |
| 관심 버튼이 화면에 들어옴 | 208 | 99% |
| 제품 소개까지 내려감 | 140 | 67% |
| 푸터까지 내려감 | 1 | 0.5% |

- 1차 사용감 광고로 도착한 기기의 99%가 인스타그램 앱 안의 브라우저였습니다.
- 2차 랜딩은 광고와 같은 문구를 첫 화면에 보여 주고 버튼을 "더 보고 싶어요"와 "관심 없어요" 둘로 나눴습니다. 114대 중 "더 보고 싶어요" 1대, "관심 없어요" 0대입니다.

**해석**
버튼을 못 봐서 안 누르는 것이 아닙니다. 방문자는 거절도 하지 않고 떠납니다. 왜 떠나는지는 이 데이터로 알 수 없습니다. 2차에서 랜딩을 고쳤지만 지금까지 달라진 것은 보이지 않습니다.

### 3.4 검증 방법과 고른 이유

**실험을 이렇게 짠 이유**

| 정한 것 | 이유 |
|---|---|
| Meta 광고 | 비교하려는 것이 그림과 문구입니다. Meta는 이미지에 문구를 얹는 광고라 그림만, 문구만 바꿔 비교할 수 있습니다. 검색 광고는 사람이 먼저 검색해야 해서 처음 보는 콘셉트를 보여 줄 수 없습니다.<br>연령, 성별, 관심사로 대상을 정해 우리를 처음 보는 사람에게 내보낼 수 있습니다.<br>하루 1만 원의 소액으로 집행할 수 있습니다.<br>광고마다 노출, 링크 클릭, CTR이 따로 나옵니다.<br>20대와 30대가 뷰티 정보를 찾는 채널 1위가 SNS입니다([CJ메조미디어 2025](https://lib.mezzomedia.co.kr/newsletter/202510/06_MezzoMedia_Beauty_campaign_knowhow.pdf), 60% 이상). |
| 대상: 20~49세 여성, 스킨케어 관심 | 성별과 연령이 섞이면 결과의 차이가 문구 때문인지 대상 때문인지 가리기 어려워서 대상을 좁혔습니다. 범위는 참고한 설문(CJ메조미디어 2025, 19~49세 여성)과 맞춰 우리 설문 답을 나란히 볼 수 있게 했습니다. |
| 단계마다 7일 | 평일과 주말의 반응 차이를 담으려고 최소 기간인 7일로 잡았습니다. |
| 성과 목표: 랜딩 페이지 조회 | 성과 목표는 Meta가 광고를 누구에게 내보낼지 정하는 기준이고 두 광고에 똑같이 걸었습니다. 비교는 CTR(링크 클릭률)로 합니다. 랜딩에서의 행동(버튼 클릭, 설문)도 함께 보려면 광고를 누른 사람이 페이지까지 실제로 들어와야 해서 누르기만 해도 세는 링크 클릭이 아니라 페이지가 열려야 세는 랜딩 페이지 조회를 골랐습니다. |
| 1차 광고 글에서 성분 이름, 사용감 말, 효능 말을 뺌 | 1차는 그림만 비교하는 단계입니다. 광고 글에 성분 이름이나 사용감 말이 들어가면 한쪽 그림(원료, 사용감)에 유리하게 작용하고 2차에서 비교할 문구를 미리 보여 주게 됩니다. 그래서 두 광고의 글을 같게 하고 이 말들을 뺐습니다. "재생" 같은 효능 말은 의약품으로 오인될 수 있는 표현이라 화장품 광고 규정 때문에 쓰지 않았습니다. |
| 후기의 말 문구 "바르면 쫀쫀해지고 광이 나는 크림" | 기준은 화해 글이 예로 든 표현 유형(바른 뒤의 밀착감, 광)입니다. 낱말은 화해 PDRN 크림 리뷰 약 110개에 실제로 나온 말에서 골랐습니다. 가장 많이 나온 말("촉촉하다", "흡수가 잘 된다")은 어느 크림에나 쓰는 말이라 쓰지 않았습니다. |

**예산을 이렇게 잡은 이유**

예산은 하루 1만 원, 단계별 7만 원(총 14만 원)입니다. 하루 1만 원은 Meta 광고가 안정적으로 게재되는 하한으로 실무에서 잡는 금액입니다. 총액은 "얼마나 작은 차이까지 볼 것인가"로 정했습니다. 계획 단계(광고 3개를 비교하던 초기 계획 기준)에서 따져 본 금액은 이렇습니다.

| 보려는 클릭률 차이 | 광고 하나당 필요한 노출 | 필요한 예산 |
|---|---|---|
| 1.0% 대 2.0% | 약 2천 회 | 약 3만 원 |
| 1.0% 대 1.5% | 약 7,800회 | 약 12만 원 |
| 1.0% 대 1.3% | 약 19,800회 | 약 30만 원 |

한 광고가 다른 광고보다 절반쯤 더 클릭받는 차이(1.0% 대 1.5%)를 볼 수 있는 12~15만 원을 골랐습니다. 1.0% 대 1.3% 같은 작은 차이까지 보려면 예산이 두 배 넘게 드는데 그 정도 차이는 확인해도 문구를 바꿀 만큼의 의미가 크지 않아 과하다고 판단했습니다. 큰 금액으로 확정하는 것이 아니라 소액으로 방향을 확인하는 것이 목적이었습니다.

**검증 방법**

| 방법 | 고른 이유 |
|---|---|
| 한 번에 하나만 바꿈(1차는 그림, 2차는 문구) | 차이가 났을 때 무엇 때문인지 가리기 위해 |
| 2차는 광고 세트 2개, 세트마다 하루 5,000원 고정 | 1차에서 한쪽 노출이 멈춰 비교할 표본이 쌓이지 않았음 |
| 함께 나간 날만 따로 비교 | 날짜 차이가 CTR 차이에 섞이는지 보기 위해 |
| Meta의 링크 클릭 수와 Amplitude의 랜딩 도착 수 대조 | 계측이 빠지는지 확인. 1차 사용감 447/464, 2차 114/117 |
| 테스트 방문으로 이벤트 확인 | 버튼 클릭이 0건일 때 계측 고장이 아닌지 가리기 위해 |
| 관찰한 수치를 노출 수와 함께 그대로 적음 | 이 규모에서는 통계 검정을 하지 않기로 함. 차이가 애매하면 기간을 늘려 더 봄 |

## 5. 한계

- 측정한 것은 클릭과 관심 버튼까지입니다. 구매가 아닙니다.
- 가상 제품이라 화해 글이 말하는 자사 리뷰를 쓸 수 없어 같은 제형 제품들의 리뷰를 빌렸습니다.
- 광고 규정 때문에 성분 이름 문구에 효능 표현을 붙이지 못했습니다. 실제 원료사 카피보다 약합니다.
- 후기의 말은 리뷰 약 110개에서 골랐고 근거가 된 표현은 6개와 4개입니다. 고른 것은 우리 판단입니다.
- 1차는 노출이 한쪽에 몰려 두 그림의 차이를 확정하지 못했습니다.
- 세트를 나눠도 Meta가 세트마다 보여 줄 사람을 고릅니다. 두 광고를 본 사람이 같은 조건이었다고 말할 수 없습니다.
- 노출의 대부분이 인스타그램 릴스와 아이폰, 20대 초반에 나갔습니다. 다른 위치와 연령에는 적용하기 어렵습니다.
- 1차 기간에 연휴(10/3 ~ 10/5)와 공휴일(10/9)이 들어 있습니다.
- 관심 버튼 클릭과 설문 응답은 한 자리 수라서 소재 간 비교에 쓰지 못했습니다.
- 구역 노출은 1차의 마지막 사흘만 기록됐습니다. 2차는 A와 B의 페이지 길이가 달라(제목 줄 수) 푸터 도달을 서로 비교하지 않습니다.
- 2차는 제출 시점에 끝나지 않았습니다. 여기 적은 2차 수치는 중간값입니다.

## 6. 실행법과 폴더 구조

```
landing/        광고 도착 페이지와 검색용 글 (정적 HTML, Vercel 배포)
  concept.html  콘셉트 페이지. 광고 이름(utm_content)에 따라 첫 화면 사진과 문구가 바뀜
  notes/        검색용 글
  privacy.html  개인정보 처리방침
ads/            광고 이미지, 광고 이름 규칙, 광고 관리자에 넣은 값
docs/taxonomy/  이벤트와 속성 정의(events.csv)와 설명
docs/workflow.md 브랜치 작업 방식, 배포, 운영 중인 랜딩에서 유지할 것
scripts/        택소노미 자동 검사(check_taxonomy.py)와 테스트
dev/active/     작업별 계획, 맥락, 할 일 기록
```

**로컬에서 열기**
```bash
python3 -m http.server 8765 --directory landing
```
브라우저에서 `http://localhost:8765/concept.html?debug=1`을 엽니다. `debug=1`을 붙이면 화면 아래에 보내는 이벤트가 보이고 분석에서 걸러집니다.

**택소노미 검사**
```bash
python3 scripts/check_taxonomy.py
cd scripts && python3 -m unittest test_check_taxonomy
```
랜딩 코드가 보내는 이벤트와 `docs/taxonomy/events.csv`가 어긋나면 실패합니다. PR마다 GitHub Actions가 같은 검사를 돌립니다.

작업 방식과 배포는 [docs/workflow.md](docs/workflow.md)에 있습니다.

**사람이 검증하거나 고친 곳**

- AI가 판단 기준을 표본 오차로 다시 계산하고 보조 기준을 바꾸는 안을 냈습니다. 강사 피드백을 받고 사람이 그 계산과 기준 숫자를 빼기로 했습니다(2026-10-07).
- 2차의 광고 세트 구성, 그림 선택, 세트별 예산은 강사 피드백과 사람의 결정입니다. AI는 1차의 노출 쏠림 수치를 조회해 근거로 냈습니다.
- AI가 프로젝트를 한 사람이 운영한다고 잘못 가정해 광고 계정 권한에 대해 답한 것을 사람이 바로잡았습니다.
- 분석에서 뺄 방문의 기준(우리나 Meta가 `debug` 없이 연 방문)은 사람이 정했습니다.
- AI가 Amplitude 조회에서 이전 값이 그대로 나오는 것을 발견해 조건을 바꿔 다시 조회했고, 문서의 수치는 다시 조회한 값입니다.
- 결과 문장은 관찰과 해석을 나눠 쓰고 데이터에 없는 이유를 붙이지 않도록 사람이 규칙을 정했습니다.
