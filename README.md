## 1. 문제 정의

**대상과 문제**
PDRN 크림 출시를 앞둔 브랜드 마케터(가정)는 출시 광고에서 성분 이름("PDRN 연어크림")과 후기의 말("바르면 쫀쫀해지고 광이 나는 크림") 중 무엇을 앞세울지 근거 없이 정해야 합니다.

**왜 이 문제인가**
- 성분 이름을 앞세운 화장품이 크게 늘었습니다. 화해에서 "PDRN"을 검색하면 제품이 1,816개 나옵니다(2026-10-01).
- 이름에 PDRN을 단 제품 6개의 성분표를 보니 3개는 PDRN이 성분표 후반부에 적혀 있었습니다.
- 화해 비즈니스는 브랜드에게 성분 이름 대신 후기의 말을 쓰라고 권합니다([글](https://business.hwahae.co.kr/insight/beauty-ingredient-marketing-guide/)). 그 말이 반응을 더 끈다는 근거는 글에 없습니다.
- 그래서 두 문구를 광고로 직접 비교했습니다.

**비즈니스 임팩트** (우리가 잰 수치만)

| 항목 | 수치 |
|---|---|
| 실험에 쓴 광고비 | 1차 69,937원. 2차는 하루 10,000원으로 진행 중 |
| 링크 클릭 한 번의 비용 | 1차 132원과 313원. 2차 201원과 216원 |
| 랜딩에 도착한 뒤 관심을 표시한 기기 | 1차 471대 중 3대 |

같은 광고비로 얻는 클릭 수가 광고에 따라 두 배 넘게 달랐고 클릭이 관심으로 이어진 비율은 1%에 못 미쳤습니다.

**성공 기준과 지표**
- Focus 지표: CTR(링크 클릭률) = 링크 클릭 ÷ 노출. 출시 전이라 구매를 잴 수 없어서 어떤 그림과 문구가 더 선택되는지를 봅니다.
- 선행지표: 광고별 노출 비중. 두 광고가 비슷하게 노출돼야 CTR을 비교할 수 있습니다.
- 보조 지표: 랜딩에 도착한 기기 중 관심 버튼을 누른 비율.
- 성공 기준은 시작 전에 정했고 중간에 바꿨습니다. 처음에는 CTR 차이를 판단하는 숫자를 두었습니다. 1차에서 노출이 한쪽에 몰려 그 숫자를 쓸 수 없었고 2차는 CTR을 노출 수와 함께 그대로 비교합니다.

PDRN 크림을 고른 이유와 가상 제품으로 한 이유는 [docs/decisions.md](docs/decisions.md)에 있습니다.

## 3. 분석과 검증

2차 수치는 2026-10-11 21:57에 조회한 중간값입니다. 일자별 수치와 본 사람의 구성은 [docs/results.md](docs/results.md)에 있습니다.

### 3.1 1차: Meta가 노출을 한쪽에 몰아줬다

| | 원료 그림 | 사용감 그림 |
|---|---|---|
| 노출 | 1,000 (7%) | 12,346 (93%) |
| CTR(링크 클릭률) | 2.80% (28/1,000) | 3.76% (464/12,346) |
| 함께 나간 이틀의 CTR | 2.72% (25/918) | 2.89% (80/2,768) |

- 사실: 원료 그림은 10/5부터 노출이 멈췄습니다. 본 사람의 구성도 달랐습니다(20~24세 23% 대 62%).
- 해석: 세트 하나에 광고 두 개를 넣어 배분을 Meta에 맡긴 구조였습니다. 사실상 Meta가 그림을 고른 셈이라 두 그림의 차이는 확정하지 못했습니다.

### 3.2 2차(중간): 성분 이름 문구 대 후기의 말 문구

| | A "PDRN 연어크림" | B "바르면 쫀쫀해지고 광이 나는 크림" |
|---|---|---|
| 노출 | 2,136 (50.5%) | 2,097 (49.5%) |
| CTR(링크 클릭률) | 2.81% (60/2,136) | 2.72% (57/2,097) |

- 사실: 세트를 둘로 나누자 노출이 거의 같게 나갔습니다. 날마다 앞서는 쪽이 바뀝니다.
- 해석: 지금까지 두 문구의 CTR은 거의 같습니다. 화해 글의 권고를 뒷받침하는 차이도 반대 방향의 차이도 아직 보이지 않습니다.

### 3.3 랜딩: 버튼은 보이지만 눌리지 않는다

| | 1차 | 2차(중간) |
|---|---|---|
| 광고로 도착한 기기 | 471 | 114 |
| 관심 버튼을 누른 기기 | 3 | 1 |

- 사실: 1차에서 도착한 기기의 99%가 버튼을 화면에서 봤습니다. 제품 소개까지 내려간 기기는 67%입니다.
- 해석: 버튼을 못 봐서 안 누르는 것이 아닙니다. 왜 떠나는지는 이 데이터로 알 수 없습니다.

### 3.4 검증 방법과 고른 이유

| 방법 | 고른 이유 |
|---|---|
| 한 번에 하나만 바꿈(1차는 그림. 2차는 문구) | 차이가 났을 때 무엇 때문인지 가리기 위해 |
| 2차는 광고 세트 2개에 예산을 똑같이 고정 | 1차에서 한쪽 노출이 멈춰 비교할 표본이 쌓이지 않았음 |
| 함께 나간 날만 따로 비교 | 날짜 차이가 CTR 차이에 섞이는지 보기 위해 |
| Meta의 링크 클릭과 Amplitude의 랜딩 도착 대조 | 계측이 빠지는지 확인. 1차 447/464. 2차 114/117 |
| 관찰한 수치를 노출 수와 함께 그대로 적음 | 이 규모에서는 통계 검정을 하지 않음. 차이가 애매하면 기간을 늘려 더 봄 |

| 실험 설정 | 이유 |
|---|---|
| Meta 광고 | 그림과 문구만 바꿔 비교할 수 있고 대상을 정해 소액으로 내보낼 수 있음 |
| 20~49세 여성 | 대상이 섞이면 문구 차이인지 대상 차이인지 가리기 어려움 |
| 단계마다 7일 | 평일과 주말의 반응 차이를 담는 최소 기간 |
| 하루 1만 원. 총 14만 원 | 한 광고가 절반쯤 더 클릭받는 차이(1.0% 대 1.5%)를 볼 수 있는 규모 |

설정마다의 자세한 이유와 예산 계산은 [docs/decisions.md](docs/decisions.md)에 있습니다.

## 5. 한계

- 측정한 것은 클릭과 관심 버튼까지입니다. 구매가 아닙니다.
- 1차는 노출이 한쪽에 몰려 두 그림의 차이를 확정하지 못했습니다.
- 세트를 나눠도 Meta가 세트마다 보여 줄 사람을 고릅니다. 두 광고를 본 사람이 같은 조건이었다고 말할 수 없습니다.
- 노출의 대부분이 인스타그램 릴스와 20대 초반에 나갔습니다.
- 관심 버튼 클릭과 설문 응답은 한 자리 수라서 소재 간 비교에 쓰지 못했습니다.
- 후기 문구는 리뷰 약 110개에서 우리가 골랐고 근거가 된 표현은 6개와 4개입니다.
- 가상 제품이고 광고 규정 때문에 성분 이름 문구에 효능 표현을 붙이지 못했습니다.
- 2차는 제출 시점에 끝나지 않아 중간값입니다.

## 6. 실행법과 폴더 구조

```
landing/        광고 도착 페이지와 검색용 글 (정적 HTML, Vercel 배포)
  concept.html  콘셉트 페이지. 광고 이름(utm_content)에 따라 첫 화면 사진과 문구가 바뀜
  notes/        검색용 글
  privacy.html  개인정보 처리방침
ads/            광고 이미지, 광고 이름 규칙, 광고 관리자에 넣은 값
docs/decisions.md 실험을 이렇게 짠 이유
docs/results.md 일자별 수치와 전처리 단계
docs/taxonomy/  이벤트와 속성 정의(events.csv)와 설명
docs/workflow.md 브랜치 작업 방식, 배포, 운영 중인 랜딩에서 유지할 것
scripts/        택소노미 자동 검사(check_taxonomy.py)와 테스트
dev/active/     작업별 계획, 맥락, 할 일 기록
```

**로컬에서 열기**
```bash
python3 -m http.server 8765 --directory landing
```
브라우저에서 `http://localhost:8765/concept.html?debug=1`을 엽니다. `debug=1`을 붙이면 화면 아래에 보내는 이벤트가 보이고 분석에서 걸러집니다.

**택소노미 검사**
```bash
python3 scripts/check_taxonomy.py
cd scripts && python3 -m unittest test_check_taxonomy
```
랜딩 코드가 보내는 이벤트와 `docs/taxonomy/events.csv`가 어긋나면 실패합니다. PR마다 GitHub Actions가 같은 검사를 돌립니다.

작업 방식과 배포는 [docs/workflow.md](docs/workflow.md)에 있습니다.

- "1차 광고 끝났어 분석해줘"

**사람이 검증하거나 고친 곳**
- 광고 게시와 예산을 비롯한 광고 관리자의 모든 조작은 사람이 했습니다. AI에는 조회만 맡겼습니다.
- AI가 판단 기준을 표본 오차로 다시 계산하는 안을 냈고 사람이 그 계산과 기준 숫자를 빼기로 했습니다.
- 2차의 광고 세트 구성과 그림 선택은 사람의 결정입니다. AI는 1차의 노출 쏠림 수치를 조회해 근거로 냈습니다.
- AI가 프로젝트를 한 사람이 운영한다고 잘못 가정해 답한 것을 사람이 바로잡았습니다.
- 분석에서 뺄 방문의 기준은 사람이 정했습니다.
- 결과 문장은 관찰과 해석을 나눠 쓰고 데이터에 없는 이유를 붙이지 않도록 사람이 규칙을 정했습니다.

## 8. 나의 역할 (팀원별)

(작성 필요: 아래는 커밋 기록과 문서로 쓴 초안입니다. 본인이 맡은 부분과 내린 결정으로 고쳐 주세요)
