## 1. 문제 정의

**대상과 문제**: PDRN 크림 출시를 앞둔 브랜드 마케터(가정)는 출시 광고에서 성분 이름("PDRN 연어크림")과 후기의 말("바르면 쫀쫀해지고 광이 나는 크림") 중 무엇을 앞세울지 근거 없이 정해야 함

**왜 이 문제인가**
- 성분 이름을 앞세운 화장품이 크게 늘어남. 화해에서 "PDRN"을 검색하면 제품이 1,824개(10/12)
- 이름에 PDRN을 단 제품 6개의 성분표를 보니 3개는 PDRN이 성분표 후반부에 적혀 있음
- 화해 비즈니스는 브랜드에게 성분 이름 대신 후기의 말을 쓰라고 권함([글](https://business.hwahae.co.kr/insight/beauty-ingredient-marketing-guide/)). 그 말이 반응을 더 끈다는 근거는 글에 없음
- 그래서 두 문구를 광고로 직접 비교함

**비즈니스 임팩트** (우리가 잰 수치만)

| 항목 | 수치 |
|---|---|
| 실험에 쓴 광고비 | 1차 69,937원. 2차는 하루 10,000원으로 진행 중 |
| 링크 클릭 한 번의 비용 | 1차 사용감 그림 132원, 원료 그림 313원. 2차 A 201원, B 216원 |
| 랜딩에 도착한 뒤 관심을 표시한 기기 | 1차 471대 중 3대 |

1차는 같은 광고비로 얻는 클릭 수가 광고에 따라 두 배 넘게 다름. 도착한 기기 중 관심을 표시한 비율은 1% 미만

**성공 기준과 지표**
- Focus 지표: CTR(링크 클릭률) = 링크 클릭 ÷ 노출. 출시 전이라 구매를 잴 수 없어서 어떤 그림과 문구가 더 선택되는지를 봄
- 선행지표: 광고별 노출 비중. 게시 다음 날부터 볼 수 있고 두 광고가 비슷하게 노출돼야 CTR을 비교할 수 있음
- 보조 지표: 랜딩에 도착한 기기 중 관심 버튼을 누른 비율
- 성공 기준: 두 문구를 비슷한 규모로 노출해 CTR을 그대로 비교할 수 있게 만드는 것. 차이가 애매하면 기간을 늘려 더 봄
- 기준을 바꾼 경위: 시작 전에는 CTR 차이를 판단하는 숫자를 정해 둠. 1차에서 노출이 한쪽에 몰려 그 숫자를 쓸 수 없어서 뺌(10/7)

PDRN 크림을 고른 이유: 3.4절. 가상 제품으로 한 이유: [docs/decisions.md](docs/decisions.md)

## 3. 분석과 검증

2차 수치는 10/11 21:57에 조회한 중간값. 일자별 수치와 본 사람의 구성: [docs/results.md](docs/results.md)

차트: [광고 실험 리포트](https://seongbun-dotbogi.vercel.app/report)

### 3.1 1차: Meta가 노출을 한쪽에 몰아줌

| | 원료 그림 | 사용감 그림 |
|---|---|---|
| 노출 | 1,000 (7%) | 12,346 (93%) |
| CTR(링크 클릭률) | 2.80% (28/1,000) | 3.76% (464/12,346) |
| 함께 나간 이틀의 CTR | 2.72% (25/918) | 2.89% (80/2,768) |

- 사실: 원료 그림은 10/5부터 노출이 멈춤. 본 사람의 구성도 다름(20~24세 23% 대 62%)
- 해석: 세트 하나에 광고 두 개를 넣어 배분을 Meta에 맡긴 구조. 사실상 Meta가 그림을 골라 두 그림의 차이는 확정하지 못함

### 3.2 2차(중간): 성분 이름 문구 대 후기의 말 문구

| | A "PDRN 연어크림" | B "바르면 쫀쫀해지고 광이 나는 크림" |
|---|---|---|
| 노출 | 2,136 (50.5%) | 2,097 (49.5%) |
| CTR(링크 클릭률) | 2.81% (60/2,136) | 2.72% (57/2,097) |

- 사실: 세트를 둘로 나누자 노출이 거의 같게 나감. 날마다 앞서는 쪽이 바뀜
- 해석: 지금까지 두 문구의 CTR은 거의 같음. 화해 글의 권고를 뒷받침하는 차이도 반대 방향의 차이도 아직 보이지 않음

### 3.3 랜딩: 버튼은 보이지만 눌리지 않음

| | 1차 | 2차(중간) |
|---|---|---|
| 광고로 도착한 기기 | 471 | 114 |
| 관심 버튼을 누른 기기 | 3 | 1 |

- 사실: 구역 기록을 넣은 뒤인 1차 마지막 사흘에 도착한 210대 중 99%가 버튼을 화면에서 봄. 제품 소개까지 내려간 기기는 67%
- 해석: 버튼을 못 봐서 안 누르는 것이 아님. 왜 떠나는지는 이 데이터로 알 수 없음

### 3.4 왜 이렇게 했나: 핵심 결정과 검증 방법

**핵심 결정 5가지**

| 질문 | 답 |
|---|---|
| 왜 PDRN 크림인가 | 광고 A/B 테스트는 제품 하나에 문구만 바꿔야 해서 성분을 하나로 정함. 화해 글이 예로 든 성분이 PDRN. 나이아신아마이드는 이름에 내세우지 않은 제품에도 널리 들어가서 뺌 |
| 왜 Meta 광고인가 | 그림과 문구만 바꿔 비교할 수 있고 대상을 정해 소액으로 내보낼 수 있음. 광고마다 노출과 클릭이 따로 나옴 |
| 왜 CTR(링크 클릭률)인가 | 보고 싶은 것은 구매 전환이지만 출시 전이라 잴 수 없음. 이 단계에서 확인할 것은 어떤 그림과 문구가 더 선택되는가 |
| 왜 7일씩, 총 14만 원인가 | 7일은 평일과 주말의 차이를 담는 최소 기간. 14만 원은 한 광고가 절반쯤 더 클릭받는 차이(1.0% 대 1.5%)를 볼 수 있는 규모. 더 작은 차이까지 보려면 두 배 넘게 듦 |
| 왜 2차에서 광고 세트를 나눴나 | 1차는 세트 하나에 광고 둘을 넣어 Meta가 노출의 93%를 한쪽에 몰아줌. 세트마다 예산을 고정하자 50.5% 대 49.5%가 됨 |

대상, 성과 목표, 광고 글, 후기 문구, 예산 계산, 분석 기준까지 전체 목록: [docs/decisions.md](docs/decisions.md)

**검증 방법**

| 방법 | 고른 이유 |
|---|---|
| 한 번에 하나만 바꿈(1차는 그림. 2차는 문구) | 차이가 났을 때 무엇 때문인지 가리기 위해 |
| 2차는 광고 세트 2개에 예산을 똑같이 고정 | 1차에서 한쪽 노출이 멈춰 비교할 표본이 쌓이지 않았음 |
| 함께 나간 날만 따로 비교 | 날짜 차이가 CTR 차이에 섞이는지 보기 위해 |
| Meta의 링크 클릭과 Amplitude의 랜딩 도착 대조 | 계측이 빠지는지 확인. 1차 사용감 그림 447/464. 2차 114/117 |
| 관찰한 수치를 노출 수와 함께 그대로 적음 | 이 규모에서는 통계 검정을 하지 않음. 차이가 애매하면 기간을 늘려 더 봄 |

## 4. 해결책

| 해결책 | 나온 분석 | 누가 무엇을 하면 | 움직이는 지표 | 상태 |
|---|---|---|---|---|
| 광고 세트를 둘로 나누고 예산 고정 | 3.1 노출의 93%가 한쪽에 몰림 | 마케터가 비교할 광고마다 세트를 따로 만듦 | 노출 비중 7% 대 93% → 50.5% 대 49.5% | 2차에 적용 |
| 랜딩 첫 화면을 광고 문구와 같게 하고 버튼을 둘로 | 3.3 도착한 471대 중 3대만 관심 표시 | 광고마다 첫 화면 문구를 맞추고 거절 버튼을 함께 둠 | 버튼 클릭률. 지금까지 114대 중 1대 | 2차에 적용 |
| 3차 제안: 랜딩 개선 테스트 | 3.3과 2차 랜딩 결과 | 광고는 그대로 두고 랜딩 첫 화면만 바꿔 비교 | 버튼 클릭률. 기준값 1차 3/471과 2차 1/114 | 제안 |

**사용자 확인**: 해결책을 써 본 사람은 광고를 보고 들어온 실제 사용자

| 해결책 | 써 본 사람 | 반응 |
|---|---|---|
| 광고 세트를 나눠 두 문구를 같은 규모로 노출 | 2차 광고를 본 4,233회의 노출 | 링크 클릭 117회. 두 문구의 CTR은 2.81%와 2.72% |
| 광고 문구에 맞춘 랜딩 첫 화면과 버튼 둘 | 2차 광고를 누르고 도착한 114대 | "더 보고 싶어요" 1대. "관심 없어요" 0대 |

- 1차 랜딩(471대 중 3대)과 견주어 달라진 것이 보이지 않아 3차에서 랜딩을 다시 시험하기로 함

## 5. 한계

- 측정한 것은 클릭과 관심 버튼까지. 구매가 아님
- 1차는 노출이 한쪽에 몰려 두 그림의 차이를 확정하지 못함
- 세트를 나눠도 Meta가 세트마다 보여 줄 사람을 고름. 두 광고를 본 사람이 같은 조건이었다고 말할 수 없음
- 노출의 대부분이 인스타그램 릴스와 20대 초반에 나감
- 관심 버튼 클릭과 설문 응답은 한 자리 수라서 소재 간 비교에 쓰지 못함
- 후기 문구는 리뷰 약 110개에서 우리가 골랐고 근거가 된 표현은 6개와 4개
- 가상 제품이고 광고 규정 때문에 성분 이름 문구에 효능 표현을 붙이지 못함
- 1차 기간에 연휴(10/3 ~ 10/5)와 공휴일(10/9)이 들어 있음
- 구역 노출은 1차 마지막 사흘(10/6 ~ 10/9)만 기록됨. 처음에는 넣지 않았고 랜딩 안의 이탈 지점을 보려고 1차 중간에 넣음
- 2차는 제출 시점에 끝나지 않아 중간값

**분석에 쓰지 않은 것**: 광고와 별도로 검색용 글 한 편과 스레드, 블로그 글을 올림. 유입이 적어 이번 분석에는 쓰지 않음

## 6. 실행법과 폴더 구조

```
landing/        광고 도착 페이지와 검색용 글 (정적 HTML, Vercel 배포)
  concept.html  콘셉트 페이지. 광고 이름(utm_content)에 따라 첫 화면 사진과 문구가 바뀜
  notes/        검색용 글
  privacy.html  개인정보 처리방침
  report.html   광고 실험 리포트. scripts/make_report.py가 만듦
ads/            광고 이미지, 광고 이름 규칙, 광고 관리자에 넣은 값
docs/decisions.md 실험을 이렇게 짠 이유
docs/results.md 일자별 수치와 전처리 단계
docs/report/    리포트의 수치(data.json)와 차트 그림(슬라이드용)
docs/taxonomy/  이벤트와 속성 정의(events.csv)와 설명
docs/workflow.md 브랜치 작업 방식, 배포, 운영 중인 랜딩에서 유지할 것
scripts/        택소노미 자동 검사(check_taxonomy.py), 리포트 생성(make_report.py)과 테스트
dev/active/     작업별 계획, 맥락, 할 일 기록
```

**로컬에서 열기**
```bash
python3 -m http.server 8765 --directory landing
```
브라우저에서 `http://localhost:8765/concept.html?debug=1` 열기. `debug=1`을 붙이면 화면 아래에 보내는 이벤트가 보이고 분석에서 걸러짐

**택소노미 검사**
```bash
python3 scripts/check_taxonomy.py
cd scripts && python3 -m unittest test_check_taxonomy
```
랜딩 코드가 보내는 이벤트와 `docs/taxonomy/events.csv`가 어긋나면 실패함. PR마다 GitHub Actions가 같은 검사를 돌림

**리포트 다시 만들기**
```bash
python3 scripts/make_report.py
cd scripts && python3 -m unittest test_make_report
```
`docs/report/data.json`의 수치를 고친 뒤 실행하면 `landing/report.html`과 차트 그림이 새로 만들어짐

작업 방식과 배포: [docs/workflow.md](docs/workflow.md)

**사람이 검증하거나 고친 곳**
- 광고 게시와 예산을 비롯한 광고 관리자의 모든 조작은 사람이 함. AI에는 조회만 맡김
- AI가 판단 기준을 표본 오차로 다시 계산하는 안을 냈고 사람이 그 계산과 기준 숫자를 빼기로 함
- 2차의 광고 세트 구성과 그림 선택은 사람의 결정. AI는 1차의 노출 쏠림 수치를 조회해 근거로 냄
- AI가 프로젝트를 한 사람이 운영한다고 잘못 가정해 답한 것을 사람이 바로잡음
- 분석에서 뺄 방문의 기준은 사람이 정함
- 결과 문장은 관찰과 해석을 나눠 쓰고 데이터에 없는 이유를 붙이지 않도록 사람이 규칙을 정함

## 8. 나의 역할 (팀원별)

### 원식

**맡은 부분**
- 프로젝트의 초반 틀(분석 주제와 그 이유, 가설, 1차와 2차로 나눈 실험 구조)
- 광고 계정과 캠페인 게시와 운영(1차, 2차)
- 광고 이름과 UTM 규칙
- 이벤트 택소노미와 자동 검사
- 분석 환경 연결과 분석 기록
- 2차 광고 이미지와 등록 값
- 검색용 글과 스레드

**내가 내린 결정**
- 성분 이름 마케팅을 주제로 정하고 화해 글의 권고를 검증 대상으로 삼음
- 성분을 PDRN 하나로 정함
- 가상 제품의 콘셉트 페이지로 진행
- 1차 종료 시각을 그대로 둠
- 2차를 새 캠페인의 광고 세트 2개와 세트별 하루 5,000원으로 구성
- 판단 기준 숫자를 빼고 CTR을 그대로 비교
- 분석에서 뺄 방문의 기준

### 지원

**맡은 부분**
- 콘셉트 랜딩 페이지(구역 구성, 누른 광고와 같은 첫 화면 사진, 2차의 광고별 문구와 버튼 두 개)
- 1차 광고 이미지와 문구
- 화해 언급 정리
- 1차 결과 분석과 2차 랜딩 개선 항목 정리
- 2차 계측 점검
- 검색어 조사와 네이버 블로그 글

**내가 내린 결정**
- 누른 광고와 같은 사진을 랜딩 첫 화면에 보여 줌
- 2차 버튼을 "더 보고 싶어요"와 "관심 없어요"로 나눔
- 설문을 버튼을 누른 직후에만 띄우고 20초 타이머를 뺌
- 제품 정보는 가격대만 공개하고 버튼을 누른 사람에게만 보여 줌
- A와 B의 소개 문구와 공통 세 줄
