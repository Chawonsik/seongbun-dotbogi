# 발표자료 전면 손질 (Canva "성분돋보기 최종 발표", 21장 → 23장)

## Context
원식이 21장 전체에 피드백을 줌: 폰트, 크기, 도형, 정렬을 통일하고, 긴 글은 개조식으로 줄이고, 강조를 세련되게, 페이지별 지적 사항을 고치고, 목차 1장과 마무리 1장을 추가. 제출 마감은 10/15(목) 15:00, 발표는 10/16. 10/15 오전에는 2차 수치 갱신이 따로 있으므로 디자인 작업은 10/14 안에 끝내는 것이 목표.

정해진 것 (10/14 원식)
- 그림은 공개 저장소의 별도 브랜치(main 아님)에 올리고 그 주소로 Canva에 넣음
- 2장 라벨: 가설 · 검증 · 결론 · 제안 (Canva에서 원식이 이미 바꿈). 맨 아래 흰 박스로 강조한 방식을 참고해 네 줄을 다시 강조. 다르게 강조해도 됨
- 제목은 주제형 짧은 제목. 말할 문장은 발표자 노트로
- 디자인 틀(검정 #1c1c1e, 노랑 #ffd02f, 연노랑 #fff4c4, 흰 카드 r24, 검정 알약 라벨)은 유지

## 도구의 한계와 대응
- Canva 연결로는 글꼴 종류를 바꿀 수 없음. 지금 글꼴이 두 종류(제목용, 본문용) 섞여 있음 → **원식이 Canva에서 글꼴 하나를 고르고 "모두 변경"** (1분). 나머지 크기, 굵기, 정렬, 색은 제가 맞춤
- Canva 글자 효과(그림자, 배경 등)는 연결로 못 씀 → 강조는 도형으로: 핵심 낱말 아래 노란 형광펜 띠, 숫자 동그라미 표식, 가는 연결선과 화살표, 큰 숫자
- 페이지 추가는 연결로 가능(add_page, reorder_page)
