## 핵심 파일과 주소
- 광고 랜딩: https://seongbun-dotbogi.vercel.app/concept (`landing/concept.html`). 루트 `/` 는 `/concept` 로 넘어간다
- 개인정보 처리방침: `/privacy` (`landing/privacy.html`)
- 1차 광고 이미지와 문구: `ads/r1/`, `ads/README.md`
- 계측 기준: 노션 "계측 설계 초안" (저장소 `docs/tracking-plan-draft.md`). 이벤트와 속성의 기준은 `docs/taxonomy/events.csv`
- 배경 자료: 화해 PDRN 제품 수 1,816개(2026-10-01)만 쓴다. 2차 B 의 리뷰 언어는 화해 리뷰에서 이미 뽑았다(노션 "PDRN 크림 리뷰 태그 수집" 행). 추가 수집은 없다

## 1차 광고 (확정)
| | A | B |
|---|---|---|
| 그림 | 원료를 떠올리는 그림 (`ads/r1/r1_A_ingredient_1x1.png`: 크림 통, 유리병, 실험 접시) | 사용감을 떠올리는 그림 (`ads/r1/r1_B_texture_1x1.png`: 크림 통, 스패출러, 펴 바른 크림) |
| UTM | `utm_content=r1_name` | `utm_content=r1_review` |

- 규격 1:1 (1080x1080), 그림 안에 글자 없음
- 광고 글은 두 소재 동일
  - 기본 문구: 새 크림을 준비하고 있어요. 판매 전 콘셉트를 가장 먼저 공개해요. 이런 크림이 나온다면 써 보고 싶은지, 관심 있어요 한 번으로 알려 주세요.
  - 제목: 새 크림 콘셉트 미리 보기 / 설명: 비움 / 버튼: 더 알아보기
- 1차 광고 글 금지어: 성분 이름(PDRN, 연어), 사용감과 리뷰 말(쫀쫀, 착 붙는, 촉촉), 효능 말(탄력, 재생)
- 인스타그램은 기본 문구가 이미지 아래에 붙고 두 줄 뒤 접힌다. 페이스북은 이미지 위에 나오고 이미지 아래에 제목과 버튼이 붙는다

## 메타 광고 초안 (2026-10-01 리허설, 임시 저장 상태이고 게시 전)
넣을 값의 기준은 `ads/README.md` 의 "메타 광고 등록 순서". 아래는 광고 관리자에서 읽어 확인한 상태다.

- 광고 계정: 워밍업을 돌린 개인 광고 계정. 포트폴리오 "성분순서" 안의 광고 계정 "성분돋보기"는 비어 있고 쓰지 않는다(ID 는 노션 결정 로그 6절)
- 캠페인 "1차 이미지 비교": 트래픽, 하루 1만 원. 워밍업 캠페인을 복제해 만듦
- 광고 세트: 웹사이트, 성과 목표 랜딩 페이지 조회, 다이내믹 크리에이티브 꺼짐, 대한민국, 모든 성별, 관심사 스킨케어(화장품), 임시 일정 10/2~10/9
- 광고 `r1_name`, `r1_review`: 문구와 제목 동일, 설명 비움, 버튼 더 알아보기, 페이지 성분돋보기, 인스타그램은 페이지 이름으로 나감
  - 링크: UTM 네 값이 한 번씩, A `utm_content=r1_name`, B `utm_content=r1_review`. URL 매개변수 칸은 비움
  - 어드밴티지+ 크리에이티브 개선 사항 0/5, 필수 개선 사항 0/3, 크리에이티브 설정(웹사이트 요약, 브랜딩, 사이트 링크, 하이라이트) 모두 해제
  - 이미지는 PNG 업로드가 되지 않아 같은 그림을 JPG(화질 95%)로 두 장 모두 올림. 저장소의 원본은 PNG 그대로
- 복제하면 기본으로 켜져 있어서 직접 꺼야 했던 것: 권장 사항 적용(동영상 추가, 어드밴티지+ 크리에이티브), 기존 공감과 댓글 표시, 웹사이트 요약(예전 페이지를 읽어 "화해 데이터 기반"이라는 문구를 만들어 둠), 오버레이 추가, 음악 추가, 문구 개선, 애니메이션 추가, 관련성 높은 댓글, 밝기 및 대비 조정. 2차 캠페인을 만들 때도 같은 항목을 확인한다

### 게시 전에 정할 것 (2026-10-02 강사님 검수 때 여쭤봄)
1. 노출 위치: 지금은 어드밴티지+ 자동. 후보는 자동 또는 Facebook 피드와 Instagram 피드만
2. 연령: 지금은 어드밴티지+ 타겟이라 20~49 가 추천값이고 최소 연령 18 만 강제된다. "원래 타겟 옵션"으로 바꿔 고정할지
3. "여러 광고주의 광고": 기본으로 체크되어 있음. 끌지

### 판정에 쓰는 숫자
- CTR 은 광고 관리자의 "CTR(링크 클릭률)". "CTR(전체)"는 쓰지 않는다
- 링크 클릭은 광고를 누른 수, 랜딩 페이지 조회는 페이지가 열려 픽셀이 작동한 수라서 랜딩 페이지 조회가 더 적다

## 2차 (확정된 것)
- 본 실험. 1차에서 고른 그림 하나 위에 문구만 다르게 얹는다
- 문구: A "PDRN 연어크림", B "바르면 쫀쫀해지고 광이 나는 크림"
- 그림 선택: 1차 CTR이 높은 쪽, 차이가 0.7%p보다 작으면 관심 클릭률이 높은 쪽
- UTM: `r2_name`, `r2_review`

## 랜딩 `/concept`
- A, B 공통 한 페이지. 다른 점은 첫 화면 사진뿐: `r1_name` 은 A 사진, `r1_review` 는 B 사진, 그 밖(UTM 없음, SNS, 2차)은 `img/concept-hero.webp`. 규칙은 concept.html 머리의 `HERO` 표
- 제목 "이런 크림 써 보고 싶나요?"(2026-10-01, 이전 "새 크림을 준비하고 있어요"). 1차 광고 기본 문구는 바꾸지 않음
- 제품 이름, 성분 이름, 가격 없음. "출시 전 콘셉트, 판매하지 않아요" 표시, "출시되면 관심 있어요" 버튼, 설문 3문항(Q1 광고 이유는 광고 유입만, Q2 가장 먼저 보는 것, Q3 성분표 습관)
- 판매하지 않는다는 고지: 첫 화면 표시, 관심 버튼 뒤 안내, 처리방침 10절. 푸터는 "© 2026 성분돋보기"
- 사이트 어디에도 화해 언급 없음
- 한 줄 소개와 제품 소개의 사용감 말(쫀쫀, 윤기)은 그대로 두기로 함(2026-10-01)

## 계측
- Amplitude(키 연결됨) + 메타 픽셀(PageView). GA4 없음
- 공통 속성: UTM 네 값, round, variant, landing_page. `?debug=1` 방문은 `is_test` 로 표시되어 분석에서 거른다
- 이벤트: landing_view, interest_click, survey_view, survey_answer, survey_close, engaged_60s

## 작업 방식
- main 에 직접 커밋하지 않고 브랜치와 PR. 원식 님이 머지하면 Vercel 이 운영에 자동 배포. PR 마다 미리보기 배포가 붙는다
- 광고 사진은 GPT 로 만들고, 저장소 쪽에서는 지시문, 검수, 크기 조정만 한다
- 2차 시안 후보(예전 글자 들어간 이미지와 바탕 원본)는 로컬 `ads/r2-draft/` 에만 있다
