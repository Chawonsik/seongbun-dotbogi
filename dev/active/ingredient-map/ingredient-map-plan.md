# 유행 성분 지도 (2차 설계) 계획

승인된 설계와 계획의 원문은 아래 두 문서다. 이 파일은 요약과 순서만 담는다.

- 스펙: `docs/superpowers/specs/2026-09-28-ingredient-map-design.md`
- 크롤러 계획: `docs/superpowers/plans/2026-09-28-crawler.md`
- 랜딩 계획, 광고 계획: 크롤러 파일럿 결과가 나온 뒤 작성

## 목표
운영 중인 랜딩(https://seongbun-dotbogi.vercel.app)을 같은 주소에 덮어쓰되, 후보 성분 18개의 파일럿 실측 데이터로 채우고 실험 노트 톤으로 재스타일한다. 광고 소재는 성분을 특정하지 않는 공통 이미지 1종 x 3규격.

## 2026-09-28 결정 (원식 차 님 댓글 10건 + 크롤링 전 결정)
- 제품 선정: 검색 랭킹 상위 15개, 단종 제외, 부족하면 있는 만큼. 수집 날짜 기록
- 후보 18개: PDRN, 레티놀 계열, 나이아신아마이드, 엑소좀, 펩타이드, 글루타치온, 판테놀, 시카, 비타민C, 콜라겐, 세라마이드, 어성초, 트라넥사믹애씨드, 아젤라익애씨드, 바쿠치올, 스피큐, 각질 산 묶음(아하 바하 파하 라하), 히알루론산(비교 기준). 알로에와 녹차 제외
- 선정 기준(증가율 또는 이름 단 제품 수)은 수집 뒤 표를 보고 결정
- 위치 지표는 상대 위치. 공개 파일에 리뷰 수와 평점 없음
- 광고 문장은 Meta 본문에, 이미지는 공통. "화해" 표기 없음
- 이벤트 이름과 계측 ID, /privacy 유지
- 브랜치 + PR 로 작업. 크롤러는 우리가 만든다

## 순서
1. 크롤러 (브랜치 feat/crawler): Task 1~9 코드, Task 10 파일럿 본 실행
2. 성분 선정: trend.csv 를 보고 8~10개 확정
3. 랜딩 갱신 (브랜치 feat/landing-v2): 재스타일, 칩 확장, 초성 자동완성, 문구 중립화
4. 광고 소재 (브랜치 feat/ads): 공통 이미지 3규격, 문구 파일
